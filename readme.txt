=== SEO Monitor ===
Contributors: it-gamma
Requires at least: 6.2
Requires PHP: 8.0
Stable tag: 1.1.0

WordPress-плагин для технического SEO-мониторинга и отправки отчётов в Telegram.

Возможности:

* проверка доступности сайта, robots.txt и wp-sitemap.xml;
* контроль meta robots, canonical, HTTP-кодов и основных редиректов;
* полный обход URL из штатной карты сайта;
* поиск кириллицы в URL из sitemap;
* OAuth-интеграция с API Яндекс Вебмастера;
* ежедневная проверка индексации, диагностики и Sitemap в Яндексе;
* контроль региональности по признаку NO_REGIONS с выбираемой датой и временем проверки;
* уведомления о критических проблемах и существенном падении индексации;
* аварийная проверка каждый час через WP-Cron;
* полный отчёт по понедельникам в 10:00 МСК;
* Telegram-команды /start, /status, /report, /yandex, /region, /cyrillic и /help;
* подключение получателей только по ссылке-приглашению;
* хранение токена Telegram в зашифрованном виде;
* защита webhook секретным заголовком Telegram.

Настройка после активации: WordPress → Настройки → SEO Monitor. Яндекс Вебмастер можно подключить через OAuth callback (ClientID + Client secret) или готовым OAuth-токеном. Секреты и токены сохраняются в зашифрованном виде.

В настройках Яндекс Вебмастера можно выбрать ожидаемый регион, дату и время однократной проверки. Результат отправляется получателям Telegram. API позволяет определить наличие проблемы «регион не задан», но точное название принятого региона нужно подтвердить в интерфейсе Вебмастера.

== Changelog ==

= 1.1.1 =

* Исправлена работа ручных проверок и административных действий.
* Адрес сайта теперь автоматически определяется из настроек WordPress.
* Дата и время однократной проверки региональности выбираются администратором.
* Улучшено определение Telegram-бота и формирование ссылки-приглашения.
* Исправлена очистка запланированных задач при деактивации плагина.

= 1.1.0 =

* Добавлено безопасное OAuth-подключение к API Яндекс Вебмастера.
* Добавлена ежедневная автоматическая проверка данных Яндекса в 10:15 МСК.
* Контролируются права, индексирование, страницы в поиске, мониторинг важных страниц, обход, диагностика и Sitemap.
* URL из wp-sitemap.xml сопоставляются со страницами, реально присутствующими в поиске Яндекса.
* Добавлено уведомление при падении числа страниц в поиске на 20% и более, минимум на 5 страниц.
* Данные Яндекса добавлены в еженедельный Telegram-отчёт.
* Добавлена команда /yandex.
* Добавлен контроль региональности по признаку NO_REGIONS.
* Добавлены выбираемые дата и время однократной проверки региональности в настройках WordPress.
* Добавлены Telegram-уведомления о результате плановой проверки и изменении региональности.
* Добавлена команда /region.
* Реализовано зашифрованное хранение токенов и автоматическое продление доступа по refresh token.
