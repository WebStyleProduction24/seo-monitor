=== SEO Monitor ===
Contributors: it-gamma
Requires at least: 6.2
Requires PHP: 8.0
Stable tag: 1.0.0

Cлужебный плагин для сайта для мониторинга SEO.

Возможности:

* проверка доступности сайта, robots.txt и wp-sitemap.xml;
* контроль meta robots, canonical, HTTP-кодов и основных редиректов;
* полный обход URL из штатной карты сайта;
* аварийная проверка каждый час через WP-Cron;
* полный отчёт по понедельникам в 10:00 МСК;
* Telegram-команды /start, /status, /report и /help;
* подключение получателей только по ссылке-приглашению;
* хранение токена Telegram в зашифрованном виде;
* защита webhook секретным заголовком Telegram.

Настройка после активации: WordPress → Настройки → SEO Monitor.
