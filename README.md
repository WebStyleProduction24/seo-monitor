# Пивзавод77 — SEO Monitor

WordPress-плагин для регулярной проверки технических SEO-настроек сайта `pivzavod77.ru` и отправки отчётов через Telegram.

## Возможности

- проверка `robots.txt`, `sitemap.xml`, meta robots и canonical;
- контроль HTTP-кодов, редиректов и технических URL;
- почасовые уведомления о критических ошибках;
- еженедельные SEO-отчёты через Telegram;
- команды `/start`, `/status`, `/report` и `/help`;
- подключение получателей по защищённой ссылке;
- шифрование токена Telegram и защищённый webhook;
- обновление через публичные GitHub Releases.

## Выпуск обновления

1. Изменить номер версии в заголовке плагина, константе `VERSION`, `readme.txt` и `README.md`.
2. Создать Git-тег, например `v1.0.3`.
3. Опубликовать GitHub Release на основе этого тега.
4. Желательно прикрепить к релизу архив `pivzavod77-seo-monitor.zip` с одноимённой корневой папкой.

Если архив не прикреплён, updater использует стандартный GitHub zipball и автоматически приводит имя каталога к slug плагина.

После публикации релиза WordPress обнаружит новую версию при очередной проверке обновлений. Настройки Telegram, получатели и расписание при обновлении сохраняются.
